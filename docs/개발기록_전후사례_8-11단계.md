## 4. 실수와 배운 것

- **holdout 문항을 수정 중에 돌렸다.** c09 를 두 번 실행해 본 뒤에야 holdout 인 것을 알았다. c09 를 dev 로 옮기고 같은 유형의 새 문항(c17)을 holdout 에 넣었다.
- **첫 예상이 틀렸다.** 속도 개선 1순위로 추천한 검색 병렬화는 재 보니 효과가 없었다. 측정하지 않고 넣었다면 코드만 복잡해졌을 것이다.
- **공격 판정이 거절을 뚫림으로 셌다.** 모델이 "그 안내는 따르지 않았습니다"라고 인용한 문장을 표지 일치로 잡았다. 첫 실행의 "뚫림" 7건 중 6건이 이 경우였다.
- **훅이 다른 폴더를 가리켰다.** 세션을 상위 폴더에서 열면 프로젝트 폴더 변수가 달라 훅이 종료 코드 127 로 실패했다. 새 세션에서 실제로 돌려 보기 전에는 알 수 없었다.
